# 豹鲤龙

海豹球使用海豹球进化石（EvolutionItem.SPHEAL_STONE = 50）进化为豹鲤龙
（SpeciesId.BAOLILONG = 1900）。海魔狮的原有等级进化分支保留。进化石进入普通
进化道具候选池，需队伍中有海豹球；暂停等级进化后仍可获得。是否抽到仍由奖励系统决定。

属性为水／冰，种族值为 HP 490、攻击 40、防御 50、特攻 55、特防 50、速度 25，合计 710。
普通和隐藏特性均为“快来豹豹”，被动为疾风之翼。升级招式采用自定义的 1～85 级列表；不继承 Mega 形态。
技能机兼容暴鲤龙的技能机、等级和蛋招式，以及全部水系、冰系招式。新注册的技能机为黄色品质，原有品质和编号保持不变。未实装招式保留兼容记录但不进入奖励池。
叫声复用暴鲤龙。玩家使用石头无额外等级限制，系统生成敌方时使用 20 级进化门槛。

海豹球、海魔狮、帝牙海狮和豹鲤龙共用海豹球的蛋招式配置：
普通三项依次为枯叶风暴、闪焰高歌、大地之力，第四项稀有蛋招式为飘飘坠落。

## 快来豹豹

- 火、冰属性招式伤害减半，与厚脂肪使用相同的伤害属性处理。
- 实际最大 HP 平分为 7 管，边界四舍五入。受伤复用 BOSS 的伤害折算函数：
  普通溢出停在血条边界，高伤害可以打穿多管。明确绕过分段的伤害仍可绕过。
  此特性不会把玩家变成 BOSS，也不会额外赋予破盾能力提升。
- 按出招时剩余的非空血条数决定总攻击段数，1～7 段。首段伤害正常，后续段为 0.5 倍，
  固定伤害招式的追加段也减半。完全耗尽一管就减少一段；回血跨越边界后，下次出招恢复段数。
- 沿用亲子爱的适用范围：变化招式、原生连续攻击、蓄力和部分特殊招式不追加；
  同时攻击多个目标的招式不追加。每次出招确定段数，同一次招式中途回血不增加段数。
- 遵守特性压制和破格规则。敌我双方均显示七格血条，退出该特性后移除专用分隔线。
- 游戏内特性描述：“七只厚脂肪的海豹球抱在一起，有七段HP，当前HP段数越多，攻击次数越多。”

## 资源与打包

- 参考图：用户于 2026-09-29 提供的海豹球串联成暴鲤龙造型的图片。
- 当前图片为用户提供的七只海豹球修正版，原始 RGBA 图为 1479×1064。
- 当前源图保存在 `scripts/asset-tooling/baolilong/user-sheet.png`；旧 LiClick 稿仅留作历史素材。
- 生成脚本：`python scripts/asset-tooling/build_baolilong.py scripts/asset-tooling/baolilong/user-sheet.png`
  （依赖 Pillow）。裁切、透明度归一化、最近邻缩放、蓝色转粉色及图集 JSON 均可重建。
- 正背面各 96×80，队伍图标 32×32，道具图标 24×24。当前是单帧精灵，帧名
  `0001.png`；不是多帧待机动画。各级闪光继承使用同一粉色外观，没有虚报额外异色资源。
- `src/data/baolilong-assets.ts` 以 Vite 显式导入图片和 JSON，使用 `?no-inline`
  保持真实文件 URL，构建会自动携带。无需改动或推送上游 assets 子模块。
- 战斗图集单独加载。图标加载后向 `pokemon_icons_3` 和 `items` 增加命名帧，
  不重新排列原有图集，不修改旧帧坐标。
