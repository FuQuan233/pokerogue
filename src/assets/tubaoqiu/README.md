# 土豹球

独立物种 `SpeciesId.TUBAOQIU = 1901`，没有前置或后续进化，与海豹球分别记录图鉴、糖果、蛋招式和存档。归在第三世代。

- 水／毒；种族值 HP 130、攻击 75、防御 60、特攻 55、特防 150、速度 20，总和 490。
- 特性“发豹施令”：地面、冰招式威力 ×1.5；火、冰招式伤害 ×0.5；水招式无效并回复最大 HP 的 1/4；出场时将其他在场宝可梦（含队友）的第一特性槽改为懒惰；换下后恢复，其他特性槽不变。这是出场时的一次性效果，后续换上场的宝可梦不会自动受影响。遵守引擎的特性压制和破格规则。
- 被动食土，需解锁，不随新账号自动开放。
- 新账号默认可选，费用 7；减肥后为 6／5。旧存档缺失该物种记录时保留初始化条目。
- 糖果经济参考海豹球：解锁被动 40 糖，减肥 25／60 糖，同种蛋初始 30 糖，友好度积糖门槛也参考海豹球。
- 普通蛋，抽取权重参考海豹球的 2 费权重，不按选人费用 7 计算。初始解锁后仍可扭出。
- 野生：冰窟，不常见，全天，与海豹球同池。
- NPC：潜水员普通池、水舰队手下不常见池、水舰队干部的原海豹球池均新增土豹球。
- 蛋招式：断崖之剑、冰冻光束、偷懒、看我嘛；第四项沿用引擎稀有蛋招式机制。
- 等级招式按 2026-10-22 用户给定的 1～30 级列表配置。技能机、捕获率 255、基础经验 58、成长速度、性别比、身高体重、初始亲密度参考海豹球；叫声复用海豹球。
