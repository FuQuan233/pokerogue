# 📱 手机版作弊码指南

## 触摸屏操作说明

在手机/平板上，游戏会显示虚拟按键。作弊码同样通过点击这些虚拟按键来输入。

### 🎮 虚拟按键位置

游戏屏幕上通常有：
- **左侧：** 方向键（上下左右）
- **右侧：** 动作按钮（确认、取消等）

## 🏆 立即通关作弊码（手机版）

### 输入步骤：

1. **进入经典模式战斗**
   - 等待虚拟按键显示出来

2. **输入方向序列**（左侧方向键）
   - 点击 **上** 2次
   - 点击 **下** 2次
   - 点击 **左** 1次
   - 点击 **右** 1次
   - 点击 **左** 1次
   - 点击 **右** 1次

3. **输入确认序列**（右侧按钮）
   - 点击 **空格/动作键**（通常是右下或右侧的按钮）
   - 点击 **回车/确认键**（通常是最主要的确认按钮）

### 完整序列
```
上 上 下 下 左 右 左 右 空格 回车
↑ ↑ ↓ ↓ ← → ← → [动作] [确认]
```

## ⏱️ 重要提示

- **2秒超时**：必须在2秒内完成整个序列
- **建议快速点击**：不要停顿太久
- **手指准备好**：在输入前先找好所有按钮的位置
- **可能需要练习**：第一次可能来不及，多试几次

## 💡 手机上的技巧

### 双手操作
- 左手大拇指：控制方向键
- 右手大拇指：准备点击动作和确认键
- 快速连续点击

### 练习序列
先练习慢速输入，熟悉按钮位置：
1. 上上下下（左手）
2. 左右左右（左手）
3. 空格回车（右手）

熟悉后加快速度，在2秒内完成。

## 🐛 排查问题

### 控制台日志（移动端）

手机上也可以查看控制台：

**Android Chrome：**
1. 手机连接电脑
2. 电脑Chrome打开 `chrome://inspect`
3. 查看手机上的页面日志

**iOS Safari：**
1. iPhone连接Mac
2. Mac Safari → 开发 → 查看手机网页
3. 查看控制台

或者更简单的方法：在PC上打开游戏，使用Chrome的设备模拟器测试触摸操作。

### 如果实在来不及（2秒太短）

可以在代码中调整超时时间。在 `src/system/cheat-system.ts` 中：

```typescript
private readonly SEQUENCE_TIMEOUT = 5000; // 改成5秒
```

## 🎯 最佳实践

1. **先在PC上熟悉**
   - 用键盘 `W W S S A D A D 空格 回车` 练习
   - 掌握节奏后再在手机上尝试

2. **触摸屏建议**
   - 使用平板（屏幕更大，更容易点击）
   - 或者在代码中延长超时时间到5秒

3. **快捷方案**
   - 如果手机上实在难以输入
   - 可以在PC上先创建通关阵容
   - 然后在手机上直接使用这些阵容进行PvP
