# 手机版作弊码指南

在战斗中使用屏幕方向键和右侧虚拟按键依次输入。**末尾确认用 V 键**，不需要手机键盘回车。

| 功能 | 手机按键序列 |
| --- | --- |
| 下一击先手必杀 | `右 右 左 左 V` |
| 全队升级 | `上 下 左 右 V` |
| 增加 10,000 金钱 | `左 左 右 右 V` |
| 全队恢复 | `上 上 下 下 V` |
| 立即通关整局 | `上 上 下 下 左 右 左 右 A V` |

- **相邻两次按键间隔不超过 2 秒**，整串可以超过 2 秒。
- 下一击先手必杀请在选招前输入，只清零一个敌方目标的 HP，用后失效；变化招式不消耗，双打按所选目标生效，群攻只作用于第一个存活敌人。
- 立即通关仅限经典、挑战、随机挑战模式，会结束整局，不是只过当前关。
- A 对应动作键（键盘空格），V 对应信息/太晶键；作弊系统只在完整序列末尾将 V 视为确认，不改变 V 的原有功能。
- 键盘回车仍然可用。更完整的效果与限制见 [作弊指令文档](cheats.md)。
