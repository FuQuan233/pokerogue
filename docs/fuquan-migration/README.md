## 存档兼容

沿用上游物种拆分、融合物种、形态道具编号等转换。另补充私服随机种族值缓存键转换，并在局内存档转换成功后更新版本，避免队伍码等重复反序列化流程再次偏移道具编号。旧缓存键保留；如果新键已有数据，则保留已有随机结果。

不要把新版写出的存档直接交给旧版读取。回退游戏时应使用升级前导出的账号数据和局内存档。

## 检查与边界

本次 8 个测试文件共 46 项通过，覆盖物种注册表、七只 DIY/三只还原、账户请求、进化、融合、瞬击出场与中文提示、旧存档转换、商店和道具转移。主程序、工具脚本、GitHub 脚本和 JavaScript 配置的类型检查通过；全项目 Biome、依赖约束、beta 构建通过。

浏览器在本地离线模式完成资源加载、中文欢迎流程，进入主菜单、模式选择和初始宝可梦选择画面。主菜单的队伍挑战和随机种族值名称已确认显示中文。

账号接口测试使用模拟响应；没有使用真实玩家账号完成线上登录、读写存档，也没有覆盖每一种卷轴与每一种融合特性的组合。这次是可独立检查的本地迁移版本，不能据此宣称线上部署已经验收。

## 后续同步与回退

继续从此分支的上游基线进行增量合并；先核对上游结构变化，再调整私服功能和集中覆盖层。不要将旧的整份宝可梦数据或旧界面文件覆盖到新版。

旧 `SYNC_GUIDE.md`、`sync-upstream*` 和快捷推送脚本不再作为新版操作入口；其原文完整保存在备份分支。迁移初次完成时未推送、合并进 beta 或部署；后续推送迁移分支也不代表已上线。需要发布时先导出线上存档，在测试环境验证账号和存档往返，再决定切换。

本地安装要求 Node.js >= 24.9，按 `pnpm-lock.yaml` 安装依赖。常用检查：

```sh
pnpm install --frozen-lockfile
pnpm lint
pnpm typecheck
pnpm depcruise
pnpm build:beta
```
