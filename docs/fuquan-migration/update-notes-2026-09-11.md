# FuQuan PokéRogue 更新内容 · 2026-09-11

版本：基于原仓库 **1.12.1.0** 的私服迁移版本。

本次将项目升级到新版上游，同时迁回私服玩法和定制内容。以下说明对应迁移分支；推送代码不代表线上游戏已经更新。

## 一、宝可梦与进化内容

### 新增 Mega 形态

同步 **48 个 Mega 形态，涉及 44 个宝可梦条目**。包括雷丘 Mega X / Y、快龙、大竺葵、大力鳄，以及阿勃梭鲁、烈咬陆鲨、路卡利欧的 Mega Z 等。完整名单见文末。

同步对应的进化和形态变化配置、相关道具、招式、特性及美术资源。形态是否可用仍需满足游戏中的获得与进化条件。

### 特殊形态拆分为独立条目

| 条目 | 调整说明 |
| --- | --- |
| 牵绊变身甲贺忍蛙 | 从原甲贺忍蛙进化线的特殊形态拆出，保留牵绊变身和小智形态机制 |
| 洗翠野蛮鲈鱼（白条纹） | 从原野蛮鲈鱼的白条纹形态拆出，成为独立初始宝可梦条目 |

这两项是已有形态的整理，不代表新增两只全国图鉴宝可梦。旧存档沿用上游的物种和融合物种转换规则；单世代挑战保留上游的兼容处理。

### 现有宝可梦调整

同步新版上游的种族值、特性与被动、蛋招式、等级招式、招式学习器兼容、初始费用及进化条件调整。具体配置以迁移版本为准，以下七只 DIY 的保留配置优先。

其中，怪力、耿鬼、卡比兽、美录梅塔、铝钢龙、武道熊师的超极巨化形态，以及普隆隆姆的部分特殊形态，包含上游种族值调整。

## 三、继续保留的私服玩法

以下为迁移保留内容，不作为本次新增玩法重复计算。

- **融合规则**：各项种族值取双方较高值，最多保留四种属性，并保留双方特性与被动、特性学习和回忆功能。
- **自定义卷轴和道具池**：迁移到新版道具系统，保留原有私服道具效果和掉落配置。
- **战斗与养成**：保留好感复活、强化训练家与劲敌、伤害计算日志、解锁扭蛋、随机种族值模式及作弊功能。
- **队伍码挑战**：保留通关队伍导出、导入和挑战流程。使用导入队伍进行 AI 对战，不是双方实时联机对战。
- **中文提示**：瞬击、连击、反击继续直接显示“触发了瞬击！”“触发了连击！”“触发了反击！”，其他语言环境也显示这些中文提示。

## 四、兼容性与问题修复

- **登录请求适配**：私服 API 未放行新版客户端附带的版本请求头，本次为私服配置关闭该请求头，避免因此被浏览器拦截。尚未用真实账号验证线上登录，不能据此认定所有网络环境的登录问题已解决。
- **移除外部脚本依赖的改动保留**：新版上游已不再加载旧的 GitHub 远程 rextexteditplugin 脚本，本次未重新引入。
- **旧存档道具转换**：沿用上游形态道具编号迁移；修复已转换存档被队伍码等流程再次读取时，编号重复偏移的问题。
- **随机种族值存档**：补充特殊形态拆分后的缓存键转换，保留已有随机结果。
- **融合特性**：统一特性查询和触发所用的列表，避免同一特性被重复计入，并保留各特性的生效检查与显示名称。
- **训练家配置**：适配新版初始化时机，避免在游戏场景尚未建立时读取战斗数据。
- **界面文字**：补充队伍挑战、随机种族值等私服入口的中文名称。

## 五、数据结构与后续维护

宝可梦数据采用新版上游的注册表和分代结构，私服物种覆盖集中保存。后续更新可以在新版结构上继续同步，并单独检查私服差异。

本次保留升级前的备份分支，原 beta 分支未被替换。新版构建工具要求 Node.js 24.9 或以上，并提供独立的 lint、类型和依赖检查。
