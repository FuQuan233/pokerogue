# 作弊指令文档

## 说明

为了方便开发和测试，游戏内置了一些作弊指令。这些指令通过**游戏按键序列**激活（类似经典的科乐美秘技）。

**注意：** 作弊指令仅用于开发测试，不应在正式游戏中使用。

## 可用的作弊指令

### 1. 立即通关 (Instant Victory) 🏆
- **按键序列：** `↑ ↑ ↓ ↓ ← → ← → A Z`
- **说明：** 上上下下左右左右 + A键(ACTION) + Z键(SUBMIT)
- **功能：** 在经典模式/挑战模式/随机挑战模式中立即以当前阵容通关
- **用途：** 快速获得通关阵容以测试PvP功能
- **限制：** 仅在经典类模式中有效

### 2. 升级所有宝可梦 (Level Up All) ⬆️
- **按键序列：** `↑ ↓ ← → Z`
- **说明：** 上下左右 + Z键(SUBMIT)
- **功能：** 队伍中所有宝可梦等级+10（最高100级）
- **用途：** 快速提升宝可梦等级

### 3. 增加金钱 (Add Money) 💰
- **按键序列：** `← ← → → Z`
- **说明：** 左左右右 + Z键(SUBMIT)
- **功能：** 获得 ₽10,000
- **用途：** 快速获得购买道具的资金

### 4. 完全恢复 (Heal All) ❤️
- **按键序列：** `↑ ↑ ↓ ↓ Z`
- **说明：** 上上下下 + Z键(SUBMIT)
- **功能：** 所有宝可梦HP完全恢复，清除异常状态
- **用途：** 快速恢复队伍状态

## 按键对照表

| 游戏按键 | 默认键盘键位 | 说明 |
|---------|-------------|------|
| ↑ (UP) | W 或 ↑ | 上方向键 |
| ↓ (DOWN) | S 或 ↓ | 下方向键 |
| ← (LEFT) | A 或 ← | 左方向键 |
| → (RIGHT) | D 或 → | 右方向键 |
| Z (SUBMIT) | Z 或 空格 | 确认键 |
| A (ACTION) | X | 动作键 |

## 使用示例

### 测试PvP功能的流程：

1. 开始一局经典模式游戏
2. 组建你想要测试的队伍
3. **输入作弊码：** `↑ ↑ ↓ ↓ ← → ← → A Z`（科乐美秘技）
4. 立即通关！阵容会自动保存
5. 返回主菜单，选择"挑战对战"
6. 使用刚才保存的阵容进行PvP测试

### 输入提示

- **序列输入有2秒超时**：如果中途停顿超过2秒，需要重新输入
- **需要按顺序输入**：必须严格按照序列顺序按键
- **支持所有输入方式**：键盘、手柄、触摸屏都可以使用
- **成功提示**：控制台会显示 `[CHEAT] XXX code activated!`

## 技术细节

- 作弊系统在 `src/system/cheat-system.ts` 中实现
- 系统监听游戏内部的按键事件（`input_down`）
- 使用按键序列识别，类似科乐美秘技（Konami Code）
- 所有作弊操作都会在控制台输出日志
- 可以通过修改 `CheatSystem.setEnabled(false)` 来禁用作弊功能
- 序列超时时间为2秒（可在代码中调整 `SEQUENCE_TIMEOUT`）

## 生产环境

在发布生产版本时，建议：
1. 将 `cheat-system.ts` 中的 `enabled` 默认值改为 `false`
2. 或者完全移除作弊系统的导入

## 注意事项

- 使用作弊后的存档可能会影响游戏平衡
- 建议在单独的测试存档中使用作弊指令
- 立即通关会将波数设置为200，自动触发胜利流程
- 如果作弊码没反应，请检查：
  - 控制台是否显示 `[CHEAT] Cheat system initialized`
  - 按键顺序是否正确
  - 输入间隔是否在2秒内
  - 是否在正确的游戏模式中（立即通关仅限经典模式）
