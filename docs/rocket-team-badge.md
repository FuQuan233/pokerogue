# 火箭队工牌

- 全局永久道具，最多持有 1 个，仅加入玩家大师球级道具池，权重 24。
- 图标复用 `coin_case`；所有语言显示中文名称和用户指定的原文描述。
- 持有后允许向普通训练家、馆主、四天王、冠军等 NPC 的宝可梦投球；劲敌全部六个阶段均禁止。
- 仅解除训练家归属限制。双打必须只剩一个场上敌方目标，BOSS 血条、大师球例外、捕获率和特殊遭遇限制保持原规则。
- 捕获成功沿用图鉴登记、满队替换/放弃和挑战限制，只转移/移除被捕获宝可梦的携带道具。
- 训练家仍有同槽位替补时继续派出；全队无法战斗时正常触发训练家胜利结算。捕获失败则正常继续战斗。
- 回归测试：`test/tests/items/rocket-team-badge.test.ts`、`test/tests/battle/catching.test.ts`。
