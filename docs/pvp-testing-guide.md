# PVP 验收

功能、接口和后端上线说明见 [pvp.md](pvp.md)。旧版 localStorage 模拟上传已移除。

1. 使用两个测试账号，各准备一条本地经典通关记录，至少一队包含融合四槽、努力药、吃剩的东西和五年规划。
2. 首次上传填写中文昵称，检查队伍和昵称在另一个账号的公共列表可见；刷新页面、重新登录后仍存在。
3. 自己选择自己的上传挑战另一队，检查双方各自道具、配招、融合和能力数据。再测试同一队挑战自己，确认编号不会串用。
4. 单账号上传满 5 条后，下一条应失败；删除一条后可以再上传；他人不能删除它。
5. 复制完整分享码，在另一账号粘贴，再选择本地通关队伍开战；关闭剪贴板权限后仍能手动复制完整代码。
6. 检查双方 HP/PP 全满、异常解除；对手会选招并换人；第五回合五年规划可在双方触发。PVP 中工牌不能捕获对手。
7. 分别验证胜利、失败、保存退出；退出后原冒险存档、本地通关记录及上传快照不变，没有经典模式奖励或下一关。
8. 后端关闭时应显示不可用提示，不得伪装成上传成功；分享码功能仍能工作。

代码检查：`pnpm typecheck`、`pnpm build:beta`；前端回归文件为 `test/tests/arena/pvp.test.ts`，后端执行 `go test ./...`。
