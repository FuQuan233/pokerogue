# PvP挑战对战功能测试指南

## 快速测试流程

### 方法一：使用作弊指令（推荐）

1. **启动游戏**
   - 选择"新游戏" → "经典模式"

2. **选择初始宝可梦**
   - 选择你想要测试的初始宝可梦

3. **进入第一场战斗**
   - 开始战斗后，等待战斗界面完全加载

4. **使用作弊指令立即通关**
   - 输入按键序列：`↑ ↑ ↓ ↓ ← → ← → 空格 回车`（科乐美秘技）
   - 键盘按键：`W W S S A D A D 空格 回车`
   - **重要：** 最后两个是空格和回车，不是X和Z！
   - 游戏会立即触发通关流程
   - 当前阵容会自动保存为通关阵容

5. **测试PvP功能**
   - 返回主菜单
   - 选择"挑战对战"
   - 选择刚才保存的阵容
   - 上传阵容（因为第一次使用没有对手）

6. **创建第二个测试阵容**（可选）
   - 重复步骤1-4，但选择不同的宝可梦
   - 这样你就有两个不同的阵容可以互相对战

7. **开始PvP对战**
   - 选择"挑战对战"
   - 选择你的阵容
   - 选择对手的阵容（你之前上传的另一个阵容）
   - 开始对战！

### 方法二：正常通关（较慢）

1. 正常进行经典模式游戏
2. 完成第200波
3. 通关后自动保存阵容
4. 使用PvP功能测试

## 其他有用的作弊指令

### 快速升级队伍
- **按键序列：** `↑ ↓ ← → 回车` (键盘: W S A D 回车)
- **用途：** 如果想要高等级的宝可梦进行测试，队伍等级+10

### 增加金钱
- **按键序列：** `← ← → → 回车` (键盘: A A D D 回车)
- **用途：** 购买道具强化队伍，获得₽10,000

### 完全恢复
- **按键序列：** `↑ ↑ ↓ ↓ 回车` (键盘: W W S S 回车)
- **用途：** 恢复宝可梦HP和状态

### 按键说明
- **方向键** = WASD 或 方向键
- **SUBMIT（确认）** = 回车键
- **ACTION（动作）** = 空格键
- **CANCEL（取消）** = Backspace 或 X键
- 需要在2秒内连续输入完成

1. **多个阵容保存**
   - 通关3次以上，检查是否只保留最新3个

2. **不同游戏模式**
   - 确认只有经典/挑战/随机挑战模式保存阵容

3. **localStorage清理**
   - 清除浏览器数据后，确认上传的阵容被清空
   - 确认本地保存的阵容保持独立

## 常见问题

### Q: 按作弊键没反应？
A: 确保：
- 按键顺序正确（立即通关是：`W W S S A D A D 空格 回车`）
- **最后两个键是空格和回车**，不是X和Z！
- 在2秒内输入完整个序列
- 检查浏览器控制台F12是否有日志：
  - `[CHEAT] Cheat system initialized` - 系统已初始化
  - `[CHEAT] Button sequence: [...]` - 显示你的按键序列
  - `[CHEAT] Victory code activated!` - 成功触发
- 确保在经典模式战斗中（不是菜单或其他模式）

### Q: 没有对手可选怎么办？
A: 第一次使用时需要先上传自己的阵容，然后：
- 创建第二个通关阵容（不同的宝可梦）
- 或者在不同浏览器/隐身模式创建另一个阵容

### Q: 如何清除测试数据？
A: 打开浏览器控制台，执行：
```javascript
localStorage.removeItem('pvp_uploaded_teams');
```
