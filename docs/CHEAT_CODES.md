# 🎮 作弊码快速参考

## 最重要的 - 立即通关 🏆

```
键盘输入：W W S S A D A D 空格 回车
或使用方向键：↑ ↑ ↓ ↓ ← → ← → 空格 回车
```

**用途：** 在经典模式中立即通关，保存当前阵容用于测试PvP

## 重要提示

⏱️ **2秒超时** - 必须在2秒内输入完整序列
📝 **按顺序** - 必须严格按照顺序依次按键
🎯 **任何输入** - 支持键盘、手柄、触摸屏
✅ **检查日志** - 浏览器控制台F12可查看 `[CHEAT]` 日志

---

## 快速测试PvP流程

1. 新游戏 → 经典模式
2. 选宝可梦 → 进战斗
3. 输入：`W W S S A D A D 空格 回车`
4. 立即通关！
5. 主菜单 → 挑战对战
6. 完成！

**重要提示：**
- 最后两个键是**空格 + 回车**，不是X和Z！
- 重复3-4步可以创建多个不同阵容互相对战
