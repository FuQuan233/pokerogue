# 🎮 作弊码快速参考

## 最重要的 - 立即通关 🏆

```
键盘输入：W W S S A D A D X Z
或使用方向键：↑ ↑ ↓ ↓ ← → ← → X Z
```

**用途：** 在经典模式中立即通关，保存当前阵容用于测试PvP

---

## 其他作弊码

### 升级宝可梦 ⬆️
```
键盘：W S A D Z
方向：↑ ↓ ← → Z
效果：所有宝可梦等级+10
```

### 增加金钱 💰
```
键盘：A A D D Z
方向：← ← → → Z
效果：获得₽10,000
```

### 完全恢复 ❤️
```
键盘：W W S S Z
方向：↑ ↑ ↓ ↓ Z
效果：所有宝可梦HP满血
```

---

## 重要提示

⏱️ **2秒超时** - 必须在2秒内输入完整序列  
📝 **按顺序** - 必须严格按照顺序依次按键  
🎯 **任何输入** - 支持键盘、手柄、触摸屏  
✅ **检查日志** - 浏览器控制台F12可查看 `[CHEAT]` 日志  

---

## 快速测试PvP流程

1. 新游戏 → 经典模式
2. 选宝可梦 → 进战斗
3. 输入：`W W S S A D A D X Z`
4. 立即通关！
5. 主菜单 → 挑战对战
6. 完成！

**提示：** 重复3-4步可以创建多个不同阵容互相对战
