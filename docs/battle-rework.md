# 战斗数值与查看面板调整

## 人民万岁

保留获得时全队恢复，取消所有伤害分摊。最低者始终按全队原始/融合种族值总和判断，含倒下队员，并列者都适用。符合条件的出战者，每项种族值改为 floor((自身原值 + 全队该项最大原值) / 2)，随后应用自己的努力药等道具和等级、个体值、性格。不会用改后的种族值重新选最低者，也不会递归取其他受益者强化后的值。换下恢复，HP按比例变化；存档保留临时生效标记。

## 基因之楔

使用后开启主体与素材的本局被动；融合具有双方各一个特性槽及一个被动槽。分离沿用素材消失的原有规则，留下的主体仍开启被动。存档保留该状态，账号初始宝可梦永久被动进度不变。

## 中期训练家

经典模式95–144关普通NPC保底努力药各1层，Boss各2层，不额外增加主攻。最终库存也执行对应上限，高级道具各最多1层，剩饭与贝壳之铃只保留一种、合计最多1层。145关后恢复既有规则。已保存的敌人不重新生成。

## 概要与伤害明细

概要种族值显示当前道具计算后的值，能力值在出战时显示实际有效数值，含能力等级、特性、道具、天气和状态。针对特定对手或招式的条件修正以该次攻击的伤害记录为准。

E键查看最近回合每次命中的快照，左右切换双方、群体目标或多段命中，上下滚动查看，长行按宽度折行。记录是在实际攻击中收集，打开面板不会重新投随机数或应用特性。记录包含种族值、个体值、等级和性格计算、永久面板、能力等级倍率、实际生效的道具/特性数值变化、招式威力、攻防比、天气/会心/随机/本系/克制等倍率、固定伤害与实际扣血。替身、剩余HP、挺住及Boss血条造成的结算差异也区分显示。

日志仅保留最近回合，刷新或重启游戏清空，不写入存档。普通未命中/变化招式不形成伤害记录；目前不是完整的所有行动与中毒等间接扣血事件列表。
